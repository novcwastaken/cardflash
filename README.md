## How to build:

System dependencies:
- OpenGL
- [GLFW](https://github.com/glfw/glfw)

Build dependency: CMake


On Linux:
Run `setup.sh` for debug mode, or `release_setup.sh` for release mode, then
`build.sh` for debug, and `release_build.sh` for release mode. The binary will be
under build/ for debug, and release/ for release.
